## Agent skills

### Issue tracker

Issues live as GitHub issues in this repo (`github.com/ertugerata/futureWallet_new`). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, labels match their names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `GLOSSARY.md` at the repo root (to be created when terms are actually resolved) and `docs/adr/` for ADRs. See `docs/agents/domain.md`.
